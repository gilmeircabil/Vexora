## 5. Required Environment Variables

Set the following in the production hosting environment:

- `NODE_ENV=production`
- `PORT=5000`
- `CLIENT_URL=https://<your-production-domain>`
- `MONGODB_URI=mongodb+srv://<user>:<password>@<cluster>.mongodb.net/vexoramods`
- `JWT_SECRET=<openssl rand -hex 32>` (Must NOT be default development secret)
- `JWT_REFRESH_SECRET=<openssl rand -hex 32>`
- `TURNSTILE_SITE_KEY=<Cloudflare Site Key>`
- `TURNSTILE_SECRET_KEY=<Cloudflare Secret Key>`
- `GOOGLE_CLIENT_ID=<Google Cloud OAuth Web Client ID>` (Optional)
- `GOOGLE_CLIENT_SECRET=<Google Cloud OAuth Web Client Secret>` (Optional)

## 6. Deployment, Rollback & Backup Instructions

- **Deployment:**
  1. Build client and server: `npm run build`
  2. Start backend server: `node server/dist/index.js` (or `pm2 start server/dist/index.js`)
  3. Serve client `dist/` via Nginx, Cloudflare Pages, or Express static proxy.
- **Rollback:**
  - Git rollback command: `git checkout <previous-tag-or-commit>`
  - Re-run `npm run build && npm test`.
- **Database Backups:**
  - Daily MongoDB Atlas snapshots enabled with 7-day retention.
  - Manual backup command: `mongodump --uri="$MONGODB_URI" --out=/backups/$(date +%Y-%m-%d)`
