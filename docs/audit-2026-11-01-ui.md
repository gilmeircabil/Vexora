## 3. Changes Made

1. `client/src/components/layout/AppLayout.tsx`: Added accessible "Skip to main content" link and assigned `id="main-content"`, `tabIndex={-1}` to `<main>` landmark.
2. `client/src/pages/HomePage.tsx`: Added `aria-label="Search all tools by name, description, or keyword"` on hero search input.
3. `client/src/pages/ToolsDirectoryPage.tsx`: Added `aria-label="Search tools by name, description, or keyword"` on directory search input.
4. `client/src/pages/ToolDetailPage.tsx`: Upgraded fallback spinner to Neo-Brutalist black/yellow palette with `role="status"` and accessible label.
5. `client/src/pages/LoginPage.tsx` & `client/src/pages/RegisterPage.tsx`: Added `aria-label="Back to Homepage"` to the top navigation link.
6. `client/src/pages/DesignEditorPage.tsx`: Added `aria-label="Move page earlier"` and `aria-label="Move page later"`, with touch-friendly sizing.
